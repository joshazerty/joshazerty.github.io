AutoMeKin, spin-aware layer AutoMeKin explores reaction networks without being told what to look for: it perturbs a starting structure, finds the transition states it runs into, and assembles the mechanism from what turns up. The code comes from Emilio Martínez-Núñez's group at Santiago de Compostela. This fork adds a layer for transition-metal reactions that change spin state on the way through. It samples each multiplicity explicitly, tests whether a single-reference description holds before spending DFT time, locates the minimum-energy crossing point, puts it into the network as a node of its own, and attaches nonadiabatic hop rates. Original code: Martínez-Núñez, E.; Barnes, G. L.; Glowacki, D. R.; and co-workers. J. Comput. Chem. 2021, 42, 2036. Python, Fortran   fork
